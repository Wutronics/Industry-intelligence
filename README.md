# 行业情报库

面向长期跟踪的中文行业研究库。每周围绕一个子行业生成可复核的研究报告、更新预测台账，并提交至 `main`。

## 运行规则

- 频率：每周一 12:00（Asia/Shanghai）。
- 轮动：工业机器人与协作机器人 → 新型储能 → 半导体设备 → AI 算力基础设施 → 新能源汽车供应链 → 循环。
- 证据：优先使用监管机构、政府统计、公司公告、行业组织和原始研究；每个关键事实均附可访问链接。
- 预测：结论以“情景 + 触发条件 + 失效条件”表达，不将推测写成事实；后续报告须回顾台账中的到期预测。
- 提交：仅在资料或台账确有更新时提交；不写入任何凭据或个人信息。
